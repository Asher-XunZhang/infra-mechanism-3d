这个页面不依赖 CDN，也不经过宿主框架。把 Vite 产出的 dist/embed 整个目录复制为本文件旁的 embed/，再从相对路径加载 sglang-viewer.js；下方按钮可销毁并重新创建同一个阅读器。

复制后即可独立运行

在仓库根目录执行下面的命令，然后把 embed.html 放在同一个静态目录中。 不要只复制单个 JS 文件：Vite 可能为两个入口生成共享模块。 

npm run build
cp -R dist/embed ./embed
# 保持 embed.html 与 embed/ 同级，再通过静态服务器打开

挂载约定

  • CSS 内联在导出模块里，页面不需要额外样式表。
  • 示例用动态 import 加载相对模块，失败时会把原因写进状态条。
  • 销毁会移除宿主内的全部内容；重建会创建新的视图实例。
  • 没有用到 iframe、CDN 或宿主框架的私有 API。
